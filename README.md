This here is my first web page that I've created, it was designed to give me an alternative to the default firefox new tab page.
However I quickly stopped using it as using this stopped the behaviour in my browser of letting my type in my address bar directly on opening a tab.
Even if I just set it to the default page when opening firefox it wasn't suited for what I wanted. Instead I just left it.

It's just raw html and css. Nothing exciting. I tried using it again (mid 2025) and I updated the links to reflect that. However it simply doesn't
offer anything I want and I don't see a need for it. In the future I might build a custom dashboard that would look similar but use it for my home network
and homelab projects.
